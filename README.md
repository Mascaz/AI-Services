# AI-Services — 3D Tool Pegboard (`Left`) & Playable Neon Arcade (`Right`)

Live Site: **`https://mascaz.github.io/AI-Services/`**  
Repository: **`https://github.com/Mascaz/AI-Services`**

Interactive 3D showcase by **Maxwell Montes Diaz** built for content creators and small businesses:
- **Left Wall (The Tool Pegboard):** Custom 3D physical tools hanging on chrome hooks representing live AI tools, product visual studios, bilingual pipelines, and business simulators.
- **Right Hall (The Playable Neon Arcade):** Press-and-swipe 3D arcade cabinets that zoom straight into playable builds with zero FPS camera complexity and `0 KB` initial game-bundle overhead on page load.

## Commands

```bash
npm run dev      # Start local dev server
npm run build    # Production build
npm run deploy   # Publish dist/ directly to GitHub Pages (gh-pages)
```
